Frontend Architecture

Views (Pages)

  • Dashboard — summary metrics, top-level KPIs
  • Inventory — stock levels, reorder points by SKU
  • Orders — order status with filtering
  • Demand — forecasting trends per item
  • Spending — financial analytics breakdown
  • Reports — quarterly & monthly trend charts
  • Backlog — delayed orders, purchase order creation

Raw data in ref(), derived data in computed()

Composables

useFilters

Singleton filter state. Provides getCurrentFilters() to all views.

useI18n

EN/JA locale via localStorage. Auto-switches USD ↔ JPY (1:150).

useAuth

Mock auth (always authenticated). Profile & tasks adapt to locale.

Global Filter System

Time Period

Month 2025-01 or quarter Q1-2025. Maps to month query param.

Warehouse

San Francisco, London, Tokyo. Maps to warehouse query param.

Category

Circuit Boards, Sensors, Actuators, Controllers, Power Supplies.

Order Status

pending, processing, shipped, delivered. Orders view only.

Backend Architecture

Data Models (Pydantic)

  • InventoryItem — sku, name, category, warehouse, qty, reorder point, unit cost
  • Order — order_number, customer, items, status, dates, total_value
  • DemandForecast — item_sku, current/forecasted demand, trend
  • BacklogItem — qty needed/available, days_delayed, priority, has_purchase_order
  • PurchaseOrder — supplier, qty, unit_cost, expected_delivery, status

Mock Data Files

  • inventory.json — 20 items across 3 warehouses
  • orders.json — 240 orders, Jan–Sep 2025
  • demand_forecasts.json — 4 items with trend data
  • backlog_items.json — delayed order backlog
  • purchase_orders.json — linked to backlog items
  • spending.json — summary, monthly, category breakdown
  • transactions.json — recent transaction records

API Endpoints

Endpoint Filters Supported Description
GET/api/inventory warehouse category All inventory items. No month filter.
GET/api/orders warehouse category status month Orders with full filter support.
GET/api/dashboard/summary warehouse category status month Aggregated KPIs: inventory value, low stock, pending orders.
GET/api/demand none Demand forecasts with trend direction.
GET/api/backlog none Backlog items; dynamically adds has_purchase_order flag.
GET/api/spending/* none summary, monthly, categories, transactions.
GET/api/reports/quarterly none Quarterly stats with fulfillment rates.
GET/api/reports/monthly-trends none Month-over-month order trends.
GET/api/tasks POST DEL PATCH none Mock task management (in-memory).
POST/api/purchase-orders none Create purchase order linked to a backlog item.

Business Rules

Revenue Goals

  • Single warehouse: $800K / month
  • All warehouses YTD: $9.6M

Key Constraints

  • No persistent storage — all mutations reset on restart
  • Dates in YYYY-MM-DD format throughout
  • Quarter filter maps Q1=Jan–Mar, Q2=Apr–Jun, etc. for 2025
  • i18n: product/customer/warehouse names are translated
